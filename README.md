`render.yaml` deploys the whole app to [Render](https://render.com) (free plan): New → Blueprint → this repo.
The landing page is at `/backbone/`, the fish atlas at `/`. Set `GEMINI_API_KEY` in the Render dashboard to turn on automatic catch measuring.
